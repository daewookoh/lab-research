# lab-research — 테크플랜 연구개발전담부서

소상공인 장기재고 재유통 AI 연구 저장소. 매 평일 18:00(KST) AI 연구보조가 백로그에서 작업 하나를 수행하고 연구노트를 작성한다.

- `ROADMAP.md` — 12개월 로드맵·운영 규칙
- `DAILY_RUN.md` — 매일 실행 지침
- `backlog/` — 분기별 일 단위 작업 목록
- `notes/` — 일자별 연구노트 (`TEMPLATE.md` 양식)
- `research/YYYY-MM-DD/` — 그날 산출물
- `src/` — 코드, `tests/` — 테스트, `data/` — 스키마·합성 데이터
- `review/` — 연구책임자 검토 코멘트 (다음 실행에 반영)
