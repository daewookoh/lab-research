## 3. 상관 (`eda_v1.txt` §3, Fig 5)

sold 만의 Spearman: duration ~ 잠재 T 1.00(sold 는 T 그대로), **~ elapsed +0.19**, ~ p +0.15, ~ r −0.14, ~ log 정상가 +0.06, 나머지(수량·연차·낱개수) ≈0. recovery 는 log 정상가 +0.32, 등록수량 +0.25, p +0.22 와 상관 — 단가가 높고 수량이 많을수록 배송비 비중이 작아지기 때문.

**duration ~ elapsed +0.19 가 핵심**이다. 설계상 T 와 경과일은 독립인데 sold 만 보면 양의 상관이 생긴다 — 등록한 지 얼마 안 된 행은 짧은 T 만 sold 로 관측되기 때문. 실데이터에서도 똑같이 생기므로 D012·D021 에서 sold 만으로 회귀하면 안 된다는 근거.

범주별 KM 중앙값(중도절단 반영)은 잠재 T 중앙값과 거의 일치한다(채널: b2b 17/17, live 26/27, own_online 68/69; 브랜드: major 36/36 … unbranded 63/61). 즉 KM 은 선택 편향을 바로잡는다. 반면 sold 중앙값은 느린 범주에서 10~25일 작고(open_market 39.5 vs 53, own_online 44.5 vs 68, unbranded 41 vs 63), 빠른 b2b 는 17 vs 17 로 거의 같다 — 절단이 많을수록 편향이 크다. 판매자 권역은 효과가 설계되지 않았는데 chungcheong 69일 · gyeongsang 39일로 벌어져 보인다 — 판매자가 권역별 소수(106·257행)라 판매자 주력 소분류 구성이 섞인 결과이며, D011 v2 에서 n 이 늘면 줄어야 한다(확인 항목).

## 5. 등급 효과 — 가격 통제 전후 (`eda_v1.txt` §5, Fig 2)

등급별 평균 p(등록가/시세): S 0.92 · A 0.83 · B 0.80 · **C 0.59**. 설계에서 C 등급 등록가 계수가 0.60 이라 C 는 싸게 등록되고, 가격 승수 (p/0.8)^1.0 ≈ 0.73 이 등급 승수 2.0 을 상쇄해 관측 T 는 ≈1.5배로만 보인다. 여기에 선택 편향이 겹치면:

|---|---|---|
| 등급만 | +0.043 | +0.133 |
| + 소분류 FE | +0.135 | +0.259 |

Fig 2 의 KM 곡선 4개가 겹치는 것이 "통제 전" 모습이다. **등급 효과는 가격을 통제해야만 보인다** — 실데이터에서도 C 등급은 싸게 내놓는 것이 당연하므로, 규칙 점수(score_v0 상품잔존성 항목)가 등급만으로 점수를 주는 것은 "같은 가격이면" 이라는 조건부 해석이어야 하고, ML 모델(D022)에는 등록가/시세 비율 피처가 반드시 들어가야 한다. 또 D012 베이스라인에서 점수 vs 판매기간 상관이 약하게 나와도 등급 항목이 틀렸다고 단정하면 안 된다.

## 6. 회수율·적자 조건 (`eda_v1.txt` §6, Fig 4)

회수율 정의(판매단가×판매수량 − 수수료 − 배송비) ÷ (매입단가×등록수량)을 재계산해 전부 일치(클립 2건 제외). 매출 대비 수수료 비중 중앙값 0.05, 배송비 비중 중앙값 0.08 이지만 p90 0.41 — 적자는 배송비가 만든다.

| 조건 | 적자율 | 회수율 중앙값 |
|---|---|---|
| offline_store(배송비 0) / b2b(1회 배송) | 0.0% / 3.3% | 1.89 / 1.78 |
| open_market / social_market | 21.5% / 31.2% | 1.33 / 1.37 |
| size small / medium / large | 0.7% / 12.3% / **37.2%** | 1.69 / 1.58 / 1.30 |
| 판매단가 <5천 / 5천~1만 / >5만 | 33.3% / 27.7% / 0.0% | 1.35 / 1.30 / 1.78 |
| 판매수량 1 / 2~3 / >10 | **42.5%** / 23.1% / 6.0% | 1.16 / 1.35 / 1.66 |

적자 행의 (배송비÷판매수량)÷판매단가 중앙값 0.54 vs 흑자 0.06. 수수료율(≤0.20)만으로는 적자가 나지 않는다(매입가가 등록가의 0.35~0.60 이라 마진이 0.4 이상). 즉 v1 에서 "회수율 < 1" 은 거의 전부 **대형·저단가·소량 + 배송 채널** 조합이고, 이는 score_v0 물류효율성 항목(SHIP_COST_KRW 와 단가 비교)이 겨냥한 사례와 일치한다.

매입가 비율 반사실(매입가 × k): k=1.2(등록가의 ≈0.57)면 중앙값 1.33·적자 20%, k=1.4(≈0.67)면 1.14·34%, **k=1.6(≈0.76)면 1.00·50%**. 운영 매입가가 등록가의 60~75% 수준이라면 v1 의 "적자 13%" 는 30~50% 로 바뀌고 D012 의 회수율 해석도 완전히 달라진다 → 11-16 질문 2(매입가 비율)가 가장 영향이 큰 미답 질문.

## 7. D011·D012 에 넘기는 항목

1. **중도절단을 반영한 추정이 필수**: D012 베이스라인·D021 선형회귀는 sold 만의 OLS 가 아니라 AFT(또는 Cox·Weibull)로 하고, sold-only 결과는 "편향 대조군" 으로만 둔다. `src/eval/survival.py` 를 그대로 쓸 수 있다.
2. D013 평가지표: MAPE·±20% 적중률은 sold 행에서만 계산 가능 → 절단 행을 어떻게 평가할지(예: "T > 관측일" 맞춤 여부, C-index) 정의 필요.
3. D011 v2 확인 항목: 오라클 최대 |차이| ≤0.05, 권역 효과 소멸, 소분류별 n ≥ 100.
4. 등급·가격 상쇄 구조상 "등록가/시세 비율" 은 피처이자 추천 대상(과제 2 매입가·채널 추천)이다 — 모델이 p 를 입력받으면 "p 를 낮추면 빨리 팔린다" 는 당연한 결과가 지배하므로, D022 피처 설계 때 p 를 넣은 모형과 뺀 모형을 둘 다 봐야 한다.
