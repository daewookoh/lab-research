- **등록 시점 평가가 기준일 평가보다 낫다**(C 0.596 vs 0.580). 누출이 있는데도 더 나쁜 이유는 기준일 평가가 시즌을 평가일(11월) 기준으로 판정하고 보유기간을 기준일까지로 늘려 등록 당시 정보를 지우기 때문. 실데이터 베이스라인도 반드시 "그때 알 수 있던 정보" 로 재야 한다.
- 총점 십분위 KM 중앙값: 최저 십분위 67일 → 최고 27일, 단조 감소(Spearman −1.00), 정답 잠재 T 중앙값 66→26.5 와 거의 일치(Fig 2). sold-only 중앙값은 36→20 으로 **전 구간 15~30일 짧게** 나온다.

## 4. 6개 항목 동시 모형 → 암묵적 가중치

표준화 항목 6개를 동시에 넣은 로그정규 AFT(전체 행) vs sold-only OLS vs 오라클 OLS(잠재 T):

| 항목 | v0 가중치 | AFT β (1sd당) | sold OLS β | 오라클 β | 암묵 가중치(AFT, 음수만 정규화) |
|---|---|---|---|---|---|
| demand | 0.20 | **−0.290** | −0.208 | −0.281 | **0.42** |
| velocity | 0.20 | −0.114 | −0.058 | −0.111 | 0.17 |
| price | 0.20 | −0.220 | −0.148 | −0.213 | 0.32 |
| residual | 0.20 | **+0.160** | +0.135 | +0.145 | 0 |
| channel | 0.10 | −0.068 | −0.059 | −0.063 | 0.10 |
| logistics | 0.10 | **+0.072** | +0.043 | +0.068 | 0 |

- AFT 계수는 오라클과 거의 같다(최대 차 0.015). sold OLS 는 전부 0 쪽으로 축소(demand 0.72배, velocity 0.52배). **AFT 가 합성에서 정답을 복원한다는 D011 결론이 "점수 항목" 수준에서도 성립**한다.
- 소분류 고정효과를 넣으면 velocity β 가 −0.114 → +0.004 로 사라진다. velocity 항목(D_ref = 소분류 중앙값)은 사실상 소분류 더미의 대리이고, 소분류 안에서는 정보가 없다. demand(−0.277)·price(−0.197)는 소분류 통제 후에도 남는다.
- 가중치를 바꾸지는 않았다(§7 의 순환 참조 때문). 재배분 근거로는 **"demand·price 상향, residual·logistics 는 v2 가정 하에서 0"** 정도만 말할 수 있다.

## 5. 등급(상품잔존성) 항목은 가격 통제 조건부 — v0 항목 단위 재확인

소분류 고정효과 + 등급 더미 + residual 항목(10점당) 로그정규 AFT (가격비 proxy 사용 가능 10,732행):

| 통제 | residual β/10점 | 등급 더미 A / B / C | log p |
|---|---|---|---|
| 없음 | +0.035±0.022 | +0.046 / +0.124 / +0.351 | — |
| + log p 관측 proxy(등록가÷환산 시세, 정답 log p 와 상관 0.708) | +0.035±0.021 | +0.103 / −0.206 / +0.283 | +0.955 |
| + log p 정답 | +0.028±0.021 | +0.105 / +0.370 / +0.886 | +1.188 |

정답 log 승수는 A +0.095 / B +0.336 / C +0.693, 가격 탄력 1.0. 정답 p 를 통제하면 등급 효과가 복원되고(B 0.370, C 0.886 — C 는 과대) 관측 proxy 로는 B 가 −0.2 로 흔들린다 — proxy 노이즈(v0 §1 시세 선택이 similar·used 레코드를 섞음). **residual 항목 자체는 어느 조건에서도 유의한 음수가 아니다.** 등급 하위점수(0.30 가중)가 담아야 할 "같은 가격이면 S 가 빨리 팔린다" 는 신호는 expiry 하위점수(0.40)와 보유기간(0.15)의 역방향 잡음에 묻힌다(§6).

주의: 가격경쟁력 항목의 r = 시세÷정상가("시장이 얼마나 쳐주나")와 판매기간을 정하는 p = 등록가÷시세는 다른 양이다. v0 에는 p 가 없고, 있을 수도 없다(매입 판단 시점엔 등록가가 없음). D021·D022 에서는 "등록가를 시세의 x 배로 둔다" 는 가격 정책 피처를 명시적으로 넣어야 한다.

## 6. 진단 — 부호가 반대인 두 항목, 약한 velocity

합성 정답 열로 분해한 결과(§7 출력):

- **residual (+)**: expiry_class 별 잠재 T 중앙값 short 14 / medium 28 / long 45 / **none 56.5**. v0 의 잔여기한 하위점수는 "유통기한 없음 = 100점" 인데 v2 에서는 유통기한 없는 소분류가 가장 느리다(D008 사전값 14/30/45/60 을 그대로 물려받음). 등급(S 45.2 / C 47.0)·포장(sealed 44.9 / box_damaged 47.3)은 가격 통제 전엔 차이가 없고, 보유기간은 설계상 효과 0(ρ −0.007). 결국 residual 은 "소분류 기본속도의 역방향 대리" 가 된다.
- **logistics (+)**: 부피(small 45.8 / medium 46.9 / large 43.7)·권역(41~53, 판매자 u 의 권역 평균)은 v2 에 효과가 없고, 정상가가 높은 대분류(DE 49,800원, HB)가 느린 편이라 가치밀도 하위점수가 약한 역방향 신호가 된다.
- **velocity (약함)**: 등록 시점 D_ref 와 정답 소분류 중앙값의 Spearman 은 0.544 뿐 — 6월 이전 등록분은 0.363, 9월 이후는 0.783. D_ref 가 "그때까지 팔린 것의 sold-only 중앙값" 이라 이력이 짧을수록 (1) 표본이 적고 (2) 짧은 T 만 관측되는 편향(D010 duration~elapsed +0.19)을 그대로 갖는다. 전체 D_ref 중앙값 25일 vs KM 중앙값 46일. 정답 소분류 중앙값을 쓰면 C 0.565 → 0.614.
- 두 항목의 역부호는 **v0 가 틀렸다는 증거가 아니라 v2 가 부피·권역·보유기간 효과를 넣지 않았다는 사실의 반영**이다. 실데이터에서 같은 부호가 나오면 그때 항목을 고친다.

## 7. 순환 참조 주의 (이 베이스라인의 가장 큰 한계)

v2 승수(브랜드·시즌·채널·등급·가격탄력·판매자)는 D008 에서 **같은 AI 가 v0 명세를 알고 있는 상태에서** 가정한 것이다. demand 항목이 가장 강하게 나오는 것은 합성기가 브랜드·시즌 승수를 넣었기 때문이고, 그 승수 크기도 가정이다. 따라서 이 결과는 "v0 가 합성 가정과 얼마나 정합한가" 이지 "v0 가 현실에서 얼마나 맞는가" 가 아니다. 여기서 얻을 수 있는 것은 (1) 평가 절차(등록 시점 평가·절단 반영·오라클 병기)가 작동한다는 확인, (2) sold-only 평가의 편향 크기, (3) 항목 구조상의 문제(등급 정보 3중 반영, expiry 점수와 소분류 속도의 얽힘, D_ref 의 초기 편향) — 이 셋은 합성 가정과 무관하게 성립한다.

## 8. D013·D014·D021 이후에 넘기는 항목

1. **D013 평가지표**: C-index(`concordance_index`)를 절단 행 평가의 1차 지표로 채택 제안. 점수형 예측(순위)엔 C-index, 일수 예측엔 "T > 관측일" 적중 + sold 행 MAPE 를 병기. 베이스라인 수치: v0 총점 C 0.596, 천장 0.753.
2. **D014 분할**: 등록 시점 평가가 보여주듯 "그때 알 수 있던 정보" 가 핵심. 시간 기준 분할에서 D_ref 류 집계 피처는 train 기간 이전 거래만으로 만들어야 하고, `latent_*`·`season_state`·`total_ref` 같은 정답/누출 열은 금지 목록에 넣는다.
3. **D021·D022 피처**: velocity 대체로 소분류 **KM 중앙값**(sold-only 중앙값 대신, 25일→46일 편향 제거) ; 등록가÷시세(p) 명시 피처 ; 등급은 p 와 상호작용 ; expiry_class 는 소분류 피처와 분리.
4. **v0.1 수정 후보(아직 안 바꿈, 실데이터 후 판단)**: (a) D_ref 를 KM 중앙값으로 (b) 등급 정보의 3중 반영(residual·channel·price 상관 0.71/0.41) 정리 (c) 등급 D 경계 45점 상향 (d) 가중치 demand·price 상향. 각 수정의 효과는 같은 스크립트로 재면 된다.
